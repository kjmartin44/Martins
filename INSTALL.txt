generoutes installation
=======================

The maintained installation guide is docs/installation.md.
The documentation index is docs/index.md.

Windows PowerShell, from the folder containing pyproject.toml:

    python -m venv .venv
    .\.venv\Scripts\python.exe -m pip install -e .
    .\.venv\Scripts\python.exe -m generoutes --demo --gene DEMOGENE --out results/demo

The demo uses synthetic data and makes no network requests.
Open results/demo/report.md after it completes.

The curated tables are part of the package. Check them with:

    .\.venv\Scripts\python.exe -m generoutes.audit

docs/curated-tables.md says what each holds. The tables built from your own
runs or from openFDA are in docs/data-setup.md, group D.

Optional chemistry tools:
    .\.venv\Scripts\python.exe -m pip install -e ".[chemistry]"

Tests and development:
    .\.venv\Scripts\python.exe -m pip install -e ".[dev,chemistry]"
    .\.venv\Scripts\python.exe -m pytest -q
