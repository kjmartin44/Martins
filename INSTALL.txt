promoter-tf-drugs — quick start (Windows)
=========================================

1. Unzip this folder anywhere, e.g. C:\Users\you\Downloads\promoter_tf_drugs

2. Open a terminal IN THE FOLDER THAT CONTAINS pyproject.toml.
   (In Explorer: type  cmd  in the address bar and press Enter.)

3. Check you have numpy:
       python -c "import numpy; print(numpy.__version__)"
   If not:  pip install numpy

4. Smoke test - runs offline on FAKE data, just to prove the install works:
       python -m promoter_tf_drugs --demo --gene DEMOGENE --out results\demo
   Or just double-click run_demo.bat

   NOTE: run_demo.bat and any command with --demo use SYNTHETIC data.
   They exist only to check the install. For real results, go to step 5.

5. REAL RUN - double-click run_analysis.bat and type a gene symbol.

   Or do it by hand. Download the motif file once (~2 MB):
       curl.exe -o jaspar2024.txt https://jaspar.elixir.no/download/data/2024/CORE/JASPAR2024_CORE_vertebrates_non-redundant_pfms_jaspar.txt

   Then:
       python -m promoter_tf_drugs --gene PAH --pfm-file jaspar2024.txt --out results\PAH -v

6. Read results\PAH\report.md

How to tell demo from real
--------------------------
  DEMO: report starts with a "DEMO MODE" banner, assembly is "DEMO",
        the gene is DEMOGENE, chromosome is 1 at position 1,000,000.
  REAL: assembly is GRCh38, a real chr/coordinate, and a transcript
        selection line such as "MANE Select".

  Demo mode happens ONLY if --demo is on the command line.

Common flags
------------
  --direction down        drugs predicted to LOWER the gene (default is up)
  --upstream / --downstream   promoter window, default -1000/+200
  --chip-bed FILE         ReMap/ChIP-Atlas peaks; the real evidence step
  --tissue cns            down-weight drugs unlikely to reach the brain
  --tf-weight 0.7         lean the grade on TF evidence over drug quality
  --pvalue 1e-5           stricter motif calling
  --all-tss               genes with alternative promoters
  --demo                  offline fixtures
  -v                      show progress

If "No module named promoter_tf_drugs": you are in the wrong folder.
You must be in the one containing pyproject.toml, not inside the package.

Full documentation and the caveats that matter: README.md
Tests:  pip install pytest  then  python -m pytest tests/
