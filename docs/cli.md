## python -m promoter_tf_drugs

```text
usage: promoter-tf-drugs [-h] --gene GENE [--direction {up,down}]
                         [--species SPECIES] [--upstream UPSTREAM]
                         [--downstream DOWNSTREAM] [--all-tss]
                         [--pvalue PVALUE] [--min-ic MIN_IC]
                         [--pfm-file PFM_FILE] [--matrix-id MATRIX_IDS]
                         [--no-mask-repeats] [--no-grade]
                         [--predict-direction] [--regulon-file REGULON_FILE]
                         [--no-direct] [--design-modality] [--design-screen]
                         [--no-stabilizers] [--cell-type-check] [--lincs]
                         [--expression-file EXPRESSION_FILE]
                         [--lincs-file LINCS_FILE]
                         [--signature-file SIGNATURE_FILE] [--genetics]
                         [--proliferation {cycling,post-mitotic,mixed,unknown}]
                         [--upstream-network]
                         [--upstream-depth UPSTREAM_DEPTH]
                         [--include-unknown-direction] [--no-mechanisms]
                         [--no-improvements] [--no-outcome] [--screen]
                         [--tissue {cns}] [--tf-weight TF_WEIGHT]
                         [--chip-bed CHIP_BED] [--chip-api]
                         [--include-investigational] [--no-dgidb] [--demo]
                         [--offline] [--cache-dir CACHE_DIR] [--out OUT]
                         [--top TOP] [-v]

Find a gene's promoter, the TFs predicted to bind it, and approved drugs that
push those TFs in whichever direction moves your target gene (--direction
up|down).

options:
  -h, --help            show this help message and exit
  --gene GENE           gene symbol or Ensembl gene ID (default: None)
  --direction {up,down}
                        up: find drugs that should raise target-gene
                        expression (agonise activators, block repressors).
                        down: the inverse (block activators, agonise
                        repressors) (default: up)
  --species SPECIES
  --upstream UPSTREAM   bp 5' of the TSS (default: 1000)
  --downstream DOWNSTREAM
                        bp 3' of the TSS (default: 200)
  --all-tss             scan every distinct TSS, not just the MANE/canonical
                        one (default: False)
  --pvalue PVALUE       per-position false-positive rate for motif hits
                        (default: 0.0001)
  --min-ic MIN_IC       drop matrices below this information content (bits)
                        (default: 6.0)
  --pfm-file PFM_FILE   local JASPAR-format PFM file (recommended) (default:
                        None)
  --matrix-id MATRIX_IDS
                        restrict to specific JASPAR matrix IDs (repeatable)
                        (default: None)
  --no-mask-repeats     scan repeat-masked (lowercase) sequence too; off by
                        default because Alu/simple repeats generate large
                        numbers of spurious hits (default: False)
  --no-grade            skip drug grading (faster; grading costs ~3 ChEMBL
                        calls per drug on the first run) (default: False)
  --predict-direction   independently predict agonist vs antagonist from
                        ligand structure (needs: pip install rdkit scikit-
                        learn). Trains a per-receptor classifier on ChEMBL
                        labels and flags rows where it disagrees with the
                        database annotation (default: False)
  --regulon-file REGULON_FILE
                        TRRUST/DoRothEA TF-target TSV. Scores how many GENES
                        each TF controls - a drug hitting one protein that
                        runs 5000 genes is not specific. Without this, coarse
                        bundled tiers are used.
                        https://www.grnpedia.org/trrust/ (default: None)
  --no-direct           skip the search for drugs targeting the gene itself
                        (default: False)
  --design-modality     DESIGN a direct modality for this gene rather than
                        looking up existing ones: siRNA and ASO candidates
                        from the transcript, CRISPRi guides, and a
                        deliverability verdict for the tissue you named in
                        --tissue (default: False)
  --design-screen       design the wet-lab screen this analysis prioritises:
                        reporter construct with controls, CRISPRa sgRNAs, and
                        a cherry-pick compound list with realistic hit rates
                        (default: False)
  --no-stabilizers      skip the stabilisation section (conformational
                        stabilisers, molecular glues, degradation blockers) —
                        the routes that work on TFs with no ligand pocket
                        (default: False)
  --cell-type-check     check that each TF is expressed in the same tissues as
                        your gene, and that the drug reaches them. Heavily
                        down-weights factors with no tissue overlap (default:
                        False)
  --lincs               query LINCS L1000 drug/gene expression signatures;
                        distinguishes measured landmarks from inferred values
                        (default: False)
  --expression-file EXPRESSION_FILE
                        local tissue-expression table (HPA
                        rna_tissue_consensus.tsv or a GTEx median-TPM matrix).
                        Replaces the Open Targets lookup entirely — faster,
                        reproducible, and works with no network (default:
                        None)
  --lincs-file LINCS_FILE
                        local drug/gene signature table
                        (drug,gene,score[,cell_line,is_landmark]) exported
                        from CLUE or iLINCS. Offline replacement for --lincs
                        (default: None)
  --signature-file SIGNATURE_FILE
                        reference gene,score signature; records the gene count
                        when --lincs or --lincs-file is active. Does not run a
                        connectivity search (default: None)
  --genetics            human genetic evidence via Open Targets: what
                        phenotypes associate with variation in this gene
                        (drug-target MR in reverse) (default: False)
  --proliferation {cycling,post-mitotic,mixed,unknown}
                        proliferation state of your target tissue. post-
                        mitotic (neurons, cardiomyocytes) REMOVES cell-cycle-
                        restricted TFs such as E2F/FOXM1, whose targets are
                        actively repressed there; cycling down-weights them by
                        duty cycle (default: unknown)
  --upstream-network    walk upstream through signed causal edges (OmniPath)
                        to find druggable kinases/receptors controlling TFs
                        that have no direct pharmacology. Signs propagate, so
                        inhibiting an inhibitor counts as activation (default:
                        False)
  --upstream-depth UPSTREAM_DEPTH
                        max hops upstream. Each hop costs selectivity; 4 is
                        usually where paths stop being interpretable (default:
                        3)
  --include-unknown-direction
                        include curated drug-gene links that record no
                        direction. Off by default: they cannot answer the
                        question this pipeline asks, and they fill the tables
                        with UNKNOWN/unclear rows (default: False)
  --no-mechanisms       skip the orthosteric vs allosteric (PAM/NAM)
                        comparison (default: False)
  --no-improvements     skip the comparison against the current standard of
                        care (default: False)
  --no-outcome          skip the transcriptional-outcome probability chain
                        (default: False)
  --screen              virtual-screen ALL approved drugs against the top
                        receptors to find untested repurposing pairs. Slow
                        (downloads ~4000 structures once) and needs rdkit
                        (default: False)
  --tissue {cns}        down-weight drugs unlikely to reach this compartment
                        (default: None)
  --tf-weight TF_WEIGHT
                        0..1. Share of the combined grade carried by TF
                        confidence rather than drug quality. 0.5 weights them
                        equally; raise it when you trust the promoter evidence
                        (e.g. with --chip-bed) (default: 0.5)
  --chip-bed CHIP_BED   ChIP-seq peak BED (ReMap/ChIP-Atlas) for orthogonal
                        binding evidence (default: None)
  --chip-api            get ChIP evidence from the ReMap REST API instead of a
                        local BED. No multi-GB download and far faster per
                        gene; needs network access. --chip-bed wins if both
                        are given (default: False)
  --include-investigational
                        do not restrict to approved (max_phase 4) drugs
                        (default: False)
  --no-dgidb            ChEMBL only (default: False)
  --demo                run entirely offline on bundled fixtures (default:
                        False)
  --offline             fail rather than hit the network; use cached responses
                        only (default: False)
  --cache-dir CACHE_DIR
  --out OUT             output directory (default: results)
  --top TOP             rows in the report tables (default: 25)
  -v, --verbose
```

## python -m promoter_tf_drugs.shortlist

```text
usage: promoter-tf-drugs.shortlist [-h]
                                   [--preset {empirical,mechanism,novel,specific,strict}]
                                   [--max-tier MAX_TIER] [--min-tier MIN_TIER]
                                   [--min-grade {A,B,C,D,F}]
                                   [--max-steps MAX_STEPS]
                                   [--min-specificity MIN_SPECIFICITY]
                                   [--max-regulon MAX_REGULON]
                                   [--require-chip] [--require-approved]
                                   [--require-mechanism] [--exclude-withdrawn]
                                   [--exclude-black-box] [--exclude-conflicts]
                                   [--only-novel] [--only-known] [--top TOP]
                                   [--out OUT]
                                   results

Filter an existing results.json into an actionable shortlist. No network, no
re-run.

positional arguments:
  results               path to results.json from a previous run

options:
  -h, --help            show this help message and exit
  --preset {empirical,mechanism,novel,specific,strict}
                        starting point; individual flags override it
  --max-tier MAX_TIER   1 clinical … 5 hypothesis
  --min-tier MIN_TIER
  --min-grade {A,B,C,D,F}
  --max-steps MAX_STEPS
                        0 = acts on the gene, 1 = on a TF, 2+ = upstream
  --min-specificity MIN_SPECIFICITY
  --max-regulon MAX_REGULON
                        drop TFs controlling more genes than this
  --require-chip        TF must have measured binding at this promoter
  --require-approved
  --require-mechanism
  --exclude-withdrawn
  --exclude-black-box
  --exclude-conflicts   drop rows where the structural model disagrees with
                        the database annotation
  --only-novel          only drugs with no reported link to this gene
  --only-known
  --top TOP
  --out OUT             write the shortlist here as markdown
```
