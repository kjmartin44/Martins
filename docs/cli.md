## python -m promoter_tf_drugs

```text
usage: promoter-tf-drugs [-h] --gene GENE [--out OUT] [--top TOP]
                         [--direction {up,down}] [--species SPECIES]
                         [--upstream UPSTREAM] [--downstream DOWNSTREAM]
                         [--all-tss] [--pvalue PVALUE] [--min-ic MIN_IC]
                         [--pfm-file PFM_FILE] [--matrix-id MATRIX_IDS]
                         [--no-mask-repeats] [--no-grade]
                         [--predict-direction] [--regulon-file REGULON_FILE]
                         [--no-direct] [--design-modality] [--design-screen]
                         [--no-stabilizers] [--cell-type-check] [--lincs]
                         [--gtf GTF] [--has-ptc] [--genome GENOME]
                         [--promoter-fasta PROMOTER_FASTA]
                         [--expression-file EXPRESSION_FILE]
                         [--lincs-gmt UP_GMT DOWN_GMT] [--lincs-geneinfo TSV]
                         [--lincs-file LINCS_FILE]
                         [--signature-file SIGNATURE_FILE] [--genetics]
                         [--proliferation {cycling,post-mitotic,mixed,unknown}]
                         [--upstream-network]
                         [--upstream-depth UPSTREAM_DEPTH]
                         [--include-unknown-direction] [--no-mechanisms]
                         [--no-improvements] [--no-outcome] [--screen]
                         [--tissue {cns}] [--tf-activity]
                         [--activity-tissue TISSUE] [--docking-results JSON]
                         [--promoter-dna] [--screen-product]
                         [--sensitivity-scan] [--prism-file CSV]
                         [--depmap-file CSV] [--activity-permutations N]
                         [--tf-weight TF_WEIGHT] [--chip-bed CHIP_BED]
                         [--chip-api] [--include-investigational] [--no-dgidb]
                         [--find-analogs] [--no-opentargets] [--demo]
                         [--offline] [--cache-dir CACHE_DIR] [--quiet] [-v]

Find a gene's promoter, the TFs predicted to bind it, and approved drugs that
push those TFs in whichever direction moves your target gene (--direction
up|down).

options:
  -h, --help            show this help message and exit
  --gene GENE           gene symbol or Ensembl gene ID (default: None)
  --out OUT             output directory (default: results)
  --top TOP             rows in the report tables (default: 25)
  --direction {up,down}
                        up: find drugs that should raise target-gene
                        expression (agonise activators, block repressors).
                        down: the inverse (block activators, agonise
                        repressors) (default: up)
  --species SPECIES
  --upstream UPSTREAM   bp 5' of the TSS (default: 1000)
  --downstream DOWNSTREAM
                        bp 3' of the TSS (default: 200)
  --all-tss             scan every distinct TSS, not just the MANE/canonical
                        one (default: False)
  --pvalue PVALUE       per-position false-positive rate for motif hits
                        (default: 0.0001)
  --min-ic MIN_IC       drop matrices below this information content (bits)
                        (default: 6.0)
  --pfm-file PFM_FILE   local JASPAR-format PFM file (recommended) (default:
                        None)
  --matrix-id MATRIX_IDS
                        restrict to specific JASPAR matrix IDs (repeatable)
                        (default: None)
  --no-mask-repeats     scan repeat-masked (lowercase) sequence too; off by
                        default because Alu/simple repeats generate large
                        numbers of spurious hits (default: False)
  --no-grade            skip drug grading (faster; grading costs ~3 ChEMBL
                        calls per drug on the first run) (default: False)
  --predict-direction   independently predict agonist vs antagonist from
                        ligand structure (needs: pip install rdkit scikit-
                        learn). Trains a per-receptor classifier on ChEMBL
                        labels and flags rows where it disagrees with the
                        database annotation (default: False)
  --regulon-file REGULON_FILE
                        TRRUST/DoRothEA TF-target TSV. Scores how many GENES
                        each TF controls - a drug hitting one protein that
                        runs 5000 genes is not specific. Without this, coarse
                        bundled tiers are used.
                        https://www.grnpedia.org/trrust/ (default: None)
  --no-direct           skip the search for drugs targeting the gene itself
                        (default: False)
  --design-modality     DESIGN a direct modality for this gene rather than
                        looking up existing ones: siRNA and ASO candidates
                        from the transcript, CRISPRi guides, and a
                        deliverability verdict for the tissue you named in
                        --tissue (default: False)
  --design-screen       design the wet-lab screen this analysis prioritises:
                        reporter construct with controls, CRISPRa sgRNAs, and
                        a cherry-pick compound list with realistic hit rates
                        (default: False)
  --no-stabilizers      skip the stabilisation section (conformational
                        stabilisers, molecular glues, degradation blockers) —
                        the routes that work on TFs with no ligand pocket
                        (default: False)
  --cell-type-check     check that each TF is expressed in the same tissues as
                        your gene, and that the drug reaches them. Heavily
                        down-weights factors with no tissue overlap (default:
                        False)
  --lincs               query LINCS L1000 drug/gene expression signatures;
                        distinguishes measured landmarks from inferred values
                        (default: False)
  --gtf GTF             GENCODE/Ensembl GTF for the neighbouring-gene check.
                        Replaces the Ensembl overlap call, which 500s under
                        load. data/gencode.basic.gtf.gz is picked up
                        automatically if present (34 MB, from
                        ftp.ebi.ac.uk/pub/databases/gencode) (default: None)
  --has-ptc             the gene carries a premature termination codon in the
                        alleles you care about. Moves nonsense readthrough and
                        NMD inhibition to the front of the post-
                        transcriptional section, because for a PTC allele
                        those address the problem and extra transcription does
                        not (default: False)
  --genome GENOME       soft-masked genome FASTA, for fully offline runs. With
                        --gtf this removes the last Ensembl dependency: gene
                        models come from the GTF and sequence from here. A
                        UCSC hg38.fa is already soft-masked, so repeat masking
                        is unchanged. data/hg38.fa is found automatically; a
                        .fai index is built on first use (default: None)
  --promoter-fasta PROMOTER_FASTA
                        read promoter sequences from a local FASTA instead of
                        Ensembl, matched on exact coordinates. This package's
                        own promoter.fa works, so a previous run is its own
                        offline source — Ensembl 500s then cost you nothing
                        (default: None)
  --expression-file EXPRESSION_FILE
                        local tissue-expression table (HPA
                        rna_tissue_consensus.tsv or a GTEx median-TPM matrix).
                        Replaces the Open Targets lookup entirely — faster,
                        reproducible, and works with no network (default:
                        None)
  --lincs-gmt UP_GMT DOWN_GMT
                        Enrichr LINCS_L1000_Chem_Pert .gmt files. Replaces
                        SigCom, which returns HTTP 500 for days at a time.
                        data/lincs_chem_pert_{up,down}.gmt are picked up
                        automatically if present (16 MB + 14 MB) (default:
                        None)
  --lincs-geneinfo TSV  CLUE geneinfo table, which records whether each gene
                        was MEASURED on the L1000 array (978 landmarks) or
                        imputed from those that were. Without it every LINCS
                        hit is tiered as predicted, so measured evidence ranks
                        BELOW a curated ligand. data/lincs_geneinfo.txt is
                        picked up automatically if present (1.1 MB) (default:
                        None)
  --lincs-file LINCS_FILE
                        local drug/gene signature table
                        (drug,gene,score[,cell_line,is_landmark]) exported
                        from CLUE or iLINCS. Offline replacement for --lincs
                        (default: None)
  --signature-file SIGNATURE_FILE
                        reference gene,score signature; records the gene count
                        when --lincs or --lincs-file is active. Does not run a
                        connectivity search (default: None)
  --genetics            human genetic evidence via Open Targets: what
                        phenotypes associate with variation in this gene
                        (drug-target MR in reverse) (default: False)
  --proliferation {cycling,post-mitotic,mixed,unknown}
                        proliferation state of your target tissue. post-
                        mitotic (neurons, cardiomyocytes) REMOVES cell-cycle-
                        restricted TFs such as E2F/FOXM1, whose targets are
                        actively repressed there; cycling down-weights them by
                        duty cycle (default: unknown)
  --upstream-network    walk upstream through signed causal edges (OmniPath)
                        to find druggable kinases/receptors controlling TFs
                        that have no direct pharmacology. Signs propagate, so
                        inhibiting an inhibitor counts as activation (default:
                        False)
  --upstream-depth UPSTREAM_DEPTH
                        max hops upstream. Each hop costs selectivity; 4 is
                        usually where paths stop being interpretable (default:
                        3)
  --include-unknown-direction
                        include curated drug-gene links that record no
                        direction. Off by default: they cannot answer the
                        question this pipeline asks, and they fill the tables
                        with UNKNOWN/unclear rows (default: False)
  --no-mechanisms       skip the orthosteric vs allosteric (PAM/NAM)
                        comparison (default: False)
  --no-improvements     skip the comparison against the current standard of
                        care (default: False)
  --no-outcome          skip the transcriptional-outcome probability chain
                        (default: False)
  --screen              virtual-screen ALL approved drugs against the top
                        receptors to find untested repurposing pairs. Slow
                        (downloads ~4000 structures once) and needs rdkit
                        (default: False)
  --tissue {cns}        down-weight drugs unlikely to reach this compartment
                        (default: None)
  --tf-activity         infer which factors are actually ACTIVE from their
                        targets' expression (VIPER-style), instead of only
                        guessing from motifs. Uses --regulon-file, or
                        data/collectri.tsv or data/trrust.tsv if present, plus
                        --expression-file and --activity-tissue for the
                        signature. CollecTRI is the better table: it signs
                        every edge and covers about three times as many
                        factors as TRRUST. This is the independent check on
                        the motif scan: a site with a flat regulon is probably
                        scan noise (default: False)
  --activity-tissue TISSUE
                        tissue name as spelled in the expression table (e.g.
                        liver, brain, kidney) to infer TF activity in.
                        Required by --tf-activity (default: None)
  --docking-results JSON
                        fold in a docking run performed elsewhere. Written by
                        `python -m promoter_tf_drugs.docking --bundle DIR
                        --out JSON`, which is the step that needs Linux.
                        Prepare and report here, dock there (default: None)
  --promoter-dna        look for sequence features in the promoter that DNA-
                        binding small molecules prefer - quadruplexes, GC-
                        boxes, AT tracts - and propose agents only where a
                        feature beats shuffles of the same sequence. Nearly
                        every approved agent of this kind is cytotoxic
                        (default: False)
  --screen-product      virtual-screen the approved library against the GENE'S
                        OWN protein, not just the transcription factors. Finds
                        compounds whose chemistry fits the product's known
                        ligands and which nobody has annotated against it.
                        This changes what the existing protein does rather
                        than how much of it there is, so RT-qPCR will not see
                        it (default: False)
  --sensitivity-scan    correlate every approved compound in the PRISM panel
                        against each factor's CRISPR knockout profile. Finds
                        drugs that behave as though they remove the factor,
                        with no annotation of any kind behind them - the one
                        route here that can surface a compound nobody has
                        linked to the gene. Needs both the DepMap and PRISM
                        matrices on disk (default: False)
  --prism-file CSV      PRISM Repurposing LFC matrix.
                        data/Repurposing_Public_24Q2_LFC_COLLAPSED.csv is
                        picked up automatically if present, and the compound
                        list beside it turns BRD ids into drug names (default:
                        None)
  --depmap-file CSV     DepMap CRISPRGeneEffect.csv. Measures what happens to
                        a cell when each factor is knocked out, which is the
                        collateral question the regulon count stands in for.
                        data/CRISPRGeneEffect.csv is picked up automatically
                        if present; Model.csv beside it adds lineage (default:
                        None)
  --activity-permutations N
                        build an empirical null from N resampled target sets
                        instead of the analytic one. The analytic p-value
                        assumes targets are independent, which co-expression
                        makes false, so use this (2000+) before relying on a
                        number (default: 0)
  --tf-weight TF_WEIGHT
                        0..1. Share of the combined grade carried by TF
                        confidence rather than drug quality. 0.5 weights them
                        equally; raise it when you trust the promoter evidence
                        (e.g. with --chip-bed) (default: 0.5)
  --chip-bed CHIP_BED   ChIP-seq peak BED (ReMap/ChIP-Atlas) for orthogonal
                        binding evidence (default: None)
  --chip-api            get ChIP evidence from the ReMap REST API instead of a
                        local BED. No multi-GB download and far faster per
                        gene; needs network access. --chip-bed wins if both
                        are given (default: False)
  --include-investigational
                        do not restrict to approved (max_phase 4) drugs
                        (default: False)
  --no-dgidb            ChEMBL only (default: False)
  --find-analogs        search ChEMBL for approved drugs chemically similar to
                        this report's own best candidates, subtracting
                        everything already annotated at the factor. Yields one
                        or two untested pairs per factor; costs a few requests
                        (default: False)
  --no-opentargets      skip the Open Targets drug lookup. It is a third
                        independent curation and typically adds one or two
                        approved drugs per target that ChEMBL and DGIdb miss,
                        at the cost of one request per factor (default: False)
  --demo                run entirely offline on bundled fixtures (default:
                        False)
  --offline             fail rather than hit the network; use cached responses
                        only (default: False)
  --cache-dir CACHE_DIR
  --quiet               no progress checkpoints. They go to stderr, so they do
                        not touch a piped report; this is for when stderr
                        itself is being read (default: False)
  -v, --verbose
```

```text
Compare several CANDIDATE genes and narrow to the route with the least
collateral effect. The genes are treated as alternatives, so a drug recurring
across them is a warning, not corroboration.

options:
  -h, --help            show this help message and exit
  --genes GENES         comma-separated gene symbols
  --gene-file GENE_FILE
                        one gene symbol per line
  --control-gene CONTROL_GENE
                        run this gene through the identical funnel as a
                        negative control. A funnel that treats a housekeeping
                        gene the same as your candidates is not
                        discriminating, and without one an empty shortlist and
                        a broken filter look identical
  --preset {exploratory,narrow,narrow+clean}
  --max-tier MAX_TIER
  --min-grade {A,B,C,D,F}
  --max-regulon MAX_REGULON
                        drop factors controlling more genes than this
  --trustworthy-regulon
                        require a real regulon count, not a bundled tier or a
                        handful of curated targets that reflect study effort
                        rather than biology
  --min-tissue-breadth MIN_TISSUE_BREADTH
                        0..1, higher = narrower. A PROXY via the factor's
                        expression; withheld for nuclear receptors
  --max-burden {low,moderate,high,prohibitive}
  --min-paralog-specificity MIN_PARALOG_SPECIFICITY
                        0..1, higher = fewer relatives share the binding
                        pocket, so a subtype-selective ligand is more
                        achievable. Drugs whose family already has a selective
                        agent are exempt
  --require-chip
  --require-interpretable
                        also exclude genes whose evidence verdict is merely
                        'degraded', not just 'not interpretable'
  --renarrow PANEL_JSON
                        re-filter a previous panel.json with new cutoffs. No
                        network, no re-run — the point being that tuning a
                        threshold should take a second, not the tens of
                        minutes per gene a fresh run costs
  --per-gene-top PER_GENE_TOP
                        at most this many rows per gene in the surviving
                        table. filter_rows sorts by (tier, -score) across the
                        whole panel, so without this a gene with more
                        annotated pharmacology fills the table and a genuinely
                        cleaner gene with three routes falls off the bottom —
                        the ranking answering the wrong question for a tool
                        that compares genes
  --top TOP
  --out OUT
  --direction {up,down}

                        expression (agonise activators, block repressors).
                        down: the inverse (block activators, agonise
                        repressors)

                        collateral question the regulon count stands in for.
                        data/CRISPRGeneEffect.csv is picked up automatically
                        if present; Model.csv beside it adds lineage
  --activity-permutations N
                        build an empirical null from N resampled target sets
                        instead of the analytic one. The analytic p-value
                        assumes targets are independent, which co-expression
                        makes false, so use this (2000+) before relying on a
                        number
  --tf-weight TF_WEIGHT
                        0..1. Share of the combined grade carried by TF
                        confidence rather than drug quality. 0.5 weights them
                        equally; raise it when you trust the promoter evidence
                        (e.g. with --chip-bed)
  --chip-bed CHIP_BED   ChIP-seq peak BED (ReMap/ChIP-Atlas) for orthogonal
                        binding evidence
  --chip-api            get ChIP evidence from the ReMap REST API instead of a
                        local BED. No multi-GB download and far faster per
                        gene; needs network access. --chip-bed wins if both
                        are given
  --include-investigational
                        do not restrict to approved (max_phase 4) drugs
  --no-dgidb            ChEMBL only
  --find-analogs        search ChEMBL for approved drugs chemically similar to
                        this report's own best candidates, subtracting
                        everything already annotated at the factor. Yields one
                        or two untested pairs per factor; costs a few requests
  --no-opentargets      skip the Open Targets drug lookup. It is a third
                        independent curation and typically adds one or two
                        approved drugs per target that ChEMBL and DGIdb miss,
                        at the cost of one request per factor
  --demo                run entirely offline on bundled fixtures
  --offline             fail rather than hit the network; use cached responses
                        only
  --cache-dir CACHE_DIR
  --quiet               no progress checkpoints. They go to stderr, so they do
                        not touch a piped report; this is for when stderr
                        itself is being read
  -v, --verbose
```
